 # Lora to MQTT Gateay
 This is an attempt to create a gateway that recieves messages over LoRa
 from temperature sensors and then creates sensors in Home Assistant.

### Sensors created:
Battery  
Humidity  
Low Battery  
Signal  
Temperature
